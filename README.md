# Node CLI Projects

Three small command-line programs written in Node.js. Each reads its input from `process.argv`.

## Rock Paper Scissors
```bash
node rockPaperScissors.js rock
# You chose rock. Computer chose scissors. You win!
```

## Pig Latin Translator
```bash
node pigLatin.js "Pig Latin is hard to speak"
# Igpay Atinlay isway ardhay otay eakspay
```

## Caesar Cipher
```bash
node caesarCipher.js "hello world" 3
# khoor zruog
```
A positive shift moves right, a negative shift moves left.
